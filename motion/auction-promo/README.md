## Источники и адаптации

Использованы снимки реального React-прототипа из `src/pages/AuctionPage.tsx`: `/auction?role=buyer`, `&state=pending`, `&state=accepted`. Они сняты при ширине контейнера 440 CSS-пикселей и плотности 3×. Макет, тексты, суммы и состояния внутри изображений не перерисованы. В ролике показаны увеличенные фрагменты этих экранов. Обрезка исключает панель предпросмотра, тестовые ссылки и команду демонстрации ошибки.

Внешние заголовки, фон, курсор, переходы, приближение и индикатор хода — оформление видео. Заголовки первой и финальной сцен согласованы отдельно. Остальные подписи повторяют названия полей и суммы из интерфейса. Данные и успешная отправка — существующая локальная демонстрация, без серверных действий. Звук и пакет озвучки не создавались согласно брифу.

## Пересборка

Команды выполняются из корня репозитория. Нужны Python с Playwright, numpy, scipy и Pillow, Chromium, ffmpeg и ffprobe. Python-библиотеки установлены в пользовательское окружение; ffmpeg/ffprobe доступны через `~/.local/bin`.

Для повторного снятия экранов запустите прототип и укажите его фактический адрес:

```sh
npm run dev
python3 motion/auction-promo/capture.py --url http://127.0.0.1:5173
```

Снимки уже сохранены в `assets/`, поэтому для пересборки из сохранённых экранов сервер прототипа не нужен:

```sh
python3 .agents/skills/product-motion/scripts/verify_scene.py motion/auction-promo/video.html --fmt h
python3 .agents/skills/product-motion/scripts/render.py motion/auction-promo/video.html stills --fmt h --times 1.5,4.5,7.5,9.8,10.9,13.5 --out motion/auction-promo/build/stills --sheet
python3 .agents/skills/product-motion/scripts/render.py motion/auction-promo/video.html video --fmt h --out motion/auction-promo/build/auction-promo-master.mp4
ffmpeg -y -v error -i motion/auction-promo/build/auction-promo-master.mp4 -c copy -an -movflags +faststart motion/auction-promo/out/auction-promo_16x9.mp4
python3 .agents/skills/product-motion/scripts/verify_media.py motion/auction-promo/plan.js motion/auction-promo/out/auction-promo_16x9.mp4 --sheet --times 0,1.5,3.5,5.5,7.5,9.8,10.9,12,14.9
```

Превью с перемоткой: запустить локальный сервер из этой папки (`python3 -m http.server 8080`) и открыть `http://127.0.0.1:8080/video.html?preview=1`.

`build/` и MP4 в `out/` исключены из Git. Если оформление или размеры исходных экранов изменятся, после повторного захвата необходимо сверить `assets/screens.json` с прямоугольниками кадрирования в `video.html`.
